# IPF 二分类重训与肺部可视化设计

## 1. 目标与边界

本阶段的主任务是根据患者 CT 影像预测是否为特发性肺纤维化（IPF），以新版标准化出院诊断为标签。同时建立肺野/肺叶分割和可视化基础，但在没有像素级专家标注前，不将模型关注热图宣称为“纤维化分割”。

本阶段不使用临床生化指标，不处理非 IPF 亚型分类，也不训练无标注的纤维化语义分割网络。

## 2. 队列和标签口径

- 新诊断表以 `CT号` 和旧映射表连接，只用于本地处理。
- 仅保留同一患者所有新记录中 IPF 标签完全一致者。
- 标签一致且存在 index CT 的源队列为 651 人：IPF 326 人，非 IPF 325 人。
- 正式影像实验增加统一的分割输入质控门：1 例开发集 IPF 的同次检查全部候选体积均为不可解释噪声，复核后排除；全图和肺野限定两条实验臂共同使用剩余 650 人（IPF 325，非 IPF 325），不得只从肺野实验臂单侧删除。
- 21 名时序标签冲突患者单独隔离，不用于当前诊断模型；后续可作为诊断演变/进展队列。
- 66 名没有新标签的原队列患者不纳入训练和评估。
- 每位患者使用一次 index CT；全部划分以患者为单位，严禁同一患者跨训练/验证/测试。
- 旧测试集已参与方案迭代，且其 94 名一致标签患者恰好无标签修正，不再视为独立测试集。

## 3. 数据完整性和泄漏防护

在训练前生成可追溯审计报告，至少包含：

- 队列人数、类别数、排除原因及数量。
- DICOM PatientID、StudyInstanceUID、SeriesInstanceUID 和可用 SOPInstanceUID 的跨患者重复检查；若转换 sidecar 仅含代表性 SOP UID，报告必须注明尚未完成全序列逐实例 SOP 穷举。
- 影像特征精确重复和高余弦相似检查。
- CT 文件指纹、选定序列和预处理参数的版本记录；只有当输入指纹和预处理版本一致时，才可复用旧 MedSigLIP 特征，否则重新提取。
- 扫描年份、厂商、设备型号、层厚和重建核的分布与标签关联；自由文本序列/检查描述只做脱敏后的汇总审计，不进入模型。
- 单独训练“采集元数据基线”；如影像模型仅小幅高于该基线，需视为潜在域偏倚。

当前只读审计未发现跨患者 UID 重复或特征向量重复；采集元数据五折 AUC 约为 0.60–0.63，因此后续结果必须报告域偏倚对照。

## 4. 评估设计

### 4.1 锁定时间外测试

- 将扫描年份为 2024–2026 年的 83 名患者锁定为时间外测试集（非 IPF 38，IPF 45）。
- 测试集不用于特征处理选择、模型选择、超参数选择或分类阈值选择。
- 只在开发流程和验收标准固定后评估一次。

### 4.2 开发队列

- 标签源队列中 2011–2023 年有 568 人；影像输入质控排除 1 人后，正式开发队列为 567 人。时间外测试仍为 83 人。
- 主要内部稳定性评估为重复嵌套分层交叉验证：外层 5 折×3 次重复，内层用于选择正则化强度和分类阈值。
- 所有标准化、特征处理和阈值学习都只在对应训练折内拟合。
- 外层折报告 ROC-AUC、PR-AUC、灵敏度、特异度、平衡准确率、Brier 分数和校准曲线。

### 4.3 时间外测试报告

- 报告 ROC-AUC 及患者级 bootstrap 95% CI、PR-AUC、灵敏度、特异度、PPV、NPV、F1、Brier 分数和混淆矩阵。
- 比较影像模型与采集元数据基线，并使用成对 bootstrap 给出 AUC 差值置信区间。
- 结果仅用于研究，不表述为临床诊断效能。

## 5. 影像模型对照

在不触碰时间外测试集的前提下比较：

1. **原始 MedSigLIP 基线**：16 个均匀轴位层面，切片特征均值+最大池化，标准化后逻辑回归。
2. **肺野限定 MedSigLIP**：在相同层面上使用肺掩膜去除肺外信息，再进行肺区域裁剪和特征提取。
3. **采集元数据基线**：年份、厂商、设备型号、层厚和重建核，仅用于识别混杂与域偏倚；排除可能含诊断词或患者信息的自由文本描述。

暂不将文本诊断、影像报告中直接包含 IPF 含义的字段或出院记录输入模型，避免目标泄漏。

## 6. 肺野分割和可视化

### 6.1 第一阶段：可直接实施

- 使用开源 `lungmask` 预训练模型生成全肺、左右肺或肺叶掩膜。
- 保存与原 CT 几何对齐的 NIfTI 掩膜、质控 JSON 和脱敏 PNG 叠加图；全部产物放在 Git 忽略目录。
- 自动质控包括：掩膜非空、体积范围、连通域数量、左右肺是否存在、掩膜是否越界及处理异常。
- 手工复核一组分层样例：正常体积、极端体积、厚层、多厂商和自动质控失败例。
- 在肺掩膜内生成基于已训练分类器的遮挡敏感度热图，图中明确标注“模型关注区域，非纤维化语义分割”。
- 单例可视化包含轴位切片、肺叶边界、关注热图和全肺 3D 分布汇总。

### 6.2 第二阶段：真实纤维化分割

- 由专业影像科/呼吸科医生标注代表性 CT，至少区分肺实质、网格影和蜂窝影；若一致性不足，先合并为“纤维化区域”。
- 使用 3D nnU-Net/MONAI 类架构，只在肺掩膜内训练，严格按患者划分。
- 报告 Dice、超体素敏感度/阳性预测值、HD95、纤维化占全肺百分比的一致性，并进行失败病例复核。
- 只有在独立标注集上通过定量验证后，输出才可称为“纤维化分割”。

### 6.3 参考文献对实施边界的约束

- Thillai 等（AJRCCM 2024，DOI: 10.1164/rccm.202311-2185OC）的“纤维化分割”建立在胸部影像专家像素级标注、3D U-Net、肺掩膜限定、统一重采样、Dice 评估和独立队列验证之上。当前数据没有同等级别的纤维化像素标注，因此本阶段只把 `lungmask` 输出称为解剖肺野分割；分类器遮挡图不升级命名为纤维化分割。
- Nan 等（ERJ 2025，DOI: 10.1183/13993003.00981-2025）提示气道分支体积、牵拉性支气管扩张相关结构及其相对全肺体积的定量指标可能提供独立预后信号。该思路列为后续进展/预后模型的结构化影像特征方向，但不用于替代本阶段 IPF 诊断二分类的独立验证。
- 两篇研究都强调多设备/多协议适用性、独立验证、体积定量和临床变量校正。因此本阶段保留厂商、机型、层厚、重建核审计，并将肺掩膜输入与全 CT 输入作严格配对的时间外比较。

## 7. 输出产物

- 可复现的 651 人标签源队列、650 人共同影像实验队列和排除汇总（患者级文件不纳入 Git）。
- 输入指纹和泄漏/域偏倚审计报告（仅汇总结果可入 Git）。
- 嵌套交叉验证指标、锁定时间外测试指标和校准图。
- 肺野分割掩膜、质控结果、分层抽样的叠加图与 3D 可视化。
- 一份方法与限制说明，区分肺解剖分割、模型关注热图和经标注验证的纤维化分割。

## 8. 隐私和版本控制

- CT、NIfTI、DICOM、患者级表格、特征向量、掩膜、模型权重和个体预测不上传 GitHub。
- Git 仅保存代码、配置、测试、方法文档和不含个体信息的汇总结果。
- 训练和分割全部在本机执行，不将患者数据发送到 Hugging Face、GitHub 或其他外部服务。

## 9. 验收标准

- 标签源队列严格为 651 人且标签计数为 326/325；分割质控后的共同影像队列严格为 650 人且标签计数为 325/325，排除仅发生在开发集。
- 开发与时间外测试无患者、CT、Study/Series UID 重叠；SOP UID 仅在可用元数据覆盖范围内无重叠，并明确报告覆盖限制。
- 任何超参数和阈值选择不访问 2024–2026 年时间外测试标签。
- 所有主要指标带不确定性区间，且同时报告采集元数据基线。
- 肺野分割每例都有机器可读质控状态；可视化不将关注热图误称为纤维化病灶。
- 执行上传前的大文件和敏感文件扫描，确认无任何原始影像或患者级数据进入 Git 跟踪集。
